Optical Artifact Transport

A signed artifact leaves <optical-send> as an animated, fountain-coded QR sequence and is reconstructed by <optical-receive>. This page runs both elements against each other in a local loopback — it reads the sender's rendered canvas pixels each frame and feeds them into the receiver exactly as a phone camera would, so the whole pipeline runs for real without needing camera hardware. Use "Start camera instead" to try a genuine cross-device transfer.

Sender

For a real cross-device transfer: copy this key and paste it into "Trust a sender's public key" on the receiving device — each device generates its own random key on page load, so the receiver won't trust a signature it hasn't been told about.
